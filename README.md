# ?? Interview Prompter

A real-time AI teleprompter web application designed for video call interviews (Zoom, Google Meet, Teams). It captures interviewer questions via live microphone transcription (or manual input), contextually matches them against your uploaded CV/resume, and streams tailored talking points generated by Google Gemini (with support for OpenAI and Claude).

---

## ? Features

- **?? CV Parsing & RAG Context**: Drag-and-drop your PDF or DOCX resume. Sections and keywords are extracted and used to ground answers strictly in your real experience.
- **?? Live Speech-to-Text**: Uses the browser-native Web Speech API (`webkitSpeechRecognition`) for low-latency, zero-cost question transcription.
- **? Smart Question Detection**: Automatically flags question endings when silence exceeds 1.5 seconds.
- **? AI Streaming Teleprompter**: Streams answers in real-time with adjustable font size (16–48px), opacity (30–100%), and light/dark theme.
- **?? Compact Overlay Mode**: Floating, semi-transparent prompter window positioned near your webcam to minimize eye movement during video calls.
- **?? Multi-Provider Support**: Built for Google Gemini (primary), with instant toggles for OpenAI (`gpt-4o-mini`, `gpt-4o`) and Anthropic Claude (`claude-sonnet-4`, `claude-haiku-35`).
- **?? Privacy First**: Your CV and API keys are stored strictly in client-side session / `localStorage`. Nothing is saved to any backend database.
- **?? Q&A Session History & Export**: Complete transcript of questions and generated answers, exportable to Markdown with one click.

## ?? Quick Start (Local Development)

### Prerequisites
- Node.js 20+ (Node 22 or 24 recommended)
- A Google Gemini API Key ([get one free at Google AI Studio](https://aistudio.google.com/apikey))

### 1. Install Dependencies
```bash
cd interview_prompter
npm install
```

### 2. Run Locally

Open two terminals (or use your favorite task runner):

**Terminal 1 — API Server:**
```bash
npm run dev:api
```
*Starts local Express adapter on `http://localhost:3001`.*

**Terminal 2 — Frontend UI:**
```bash
npm run dev
```
*Starts Vite dev server on `http://localhost:5173`.*

### 3. Open in Browser
Navigate to `http://localhost:5173`.
1. Click **?? Settings** to enter your Gemini API Key.
2. Drag & drop your CV (or click **"Or load sample CV for testing"**).
3. Click **"Start Listening"** to enable your microphone, or type a question directly into the manual prompt bar at the bottom.

## ?? Deployment to Netlify

This project is built Netlify-ready using Netlify Functions (`netlify/functions/`) and static Vite output.

### Option A: One-Click Git Deployment (Recommended)
1. Push your repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of interview prompter"
   git remote add origin https://github.com/your-username/interview-prompter.git
   git push -u origin main
   ```
2. Log into [Netlify](https://app.netlify.com/) and click **"Add new site"** ? **"Import an existing project"**.
3. Select your GitHub repository.
4. Netlify will auto-detect settings from `netlify.toml`:
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
   - **Functions directory**: `netlify/functions`
5. Click **Deploy**. Your app is live!

### Option B: Netlify CLI
```bash
npm install -g netlify-cli
netlify login
netlify deploy --build --prod
```
